# MF_xian Blog design

The site adapts the Apache-2.0 code of joyehuang/blog and Astro Theme Pure.
See NOTICE and LICENSE for attribution.

## Structure

Use a centered profile, muted blue highlight, rounded cards and quiet typography.
Preserve light/dark themes, responsive navigation, bilingual pages and the interactive terminal.
Keep navigation and articles usable without JavaScript. Terminal and search are progressive enhancements.

## Identity and content

MF_xian is the display name; UEPBFOM is the GitHub account.
Personal information lives in src/site.identity.ts. Never infer a school, employer, location,
credentials, projects, or social accounts from the upstream author’s biography.
The avatar is a locally generated MF monogram. Do not reuse upstream personal media.

## Optional services

Analytics and Waline are disabled. The upstream private Jojo character is not included.
There is no production domain yet; PUBLIC_SITE_URL must be configured before publishing.
